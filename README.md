# Titanic Data Analysis 🚢

## About
Analysis of Titanic passenger data using Python and Pandas.

## What I explored
- Survival count (survived vs not survived)
- Survival rate by gender
- Survival rate by passenger class

## Key Findings
- Females had 74.9% survival rate vs 18.9% for males
- First class passengers had 61.6% survival rate
- Third class passengers had only 24.7% survival rate

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Dataset
Titanic dataset from Kaggle
